# AI Ads Editor

Веб-приложение для управления объявлениями со списком, страницей товара, формой редактирования и AI-помощником, который генерирует описание и предлагает цену на основе параметров объявления.

## Возможности

- Список объявлений с поиском, фильтрацией по категориям/статусу, сортировкой, пагинацией и переключением вида (плитка/список)
- Просмотр карточки объявления и редактирование его полей
- AI-генерация описания и цены объявления через Groq (LLM) прямо из формы редактирования

## Архитектура

### Общий подход — Clean Architecture (Ports & Adapters)

Каждый бизнес-модуль разбит на четыре слоя. Зависимости направлены внутрь: внешние слои знают о внутренних, но не наоборот.

```
drivers (UI)  →  applications (use cases)  →  domain (entities, ports)
                         ↑
                infrastructure (adapters: API, mapper, DTO)
```

### Структура директорий

```
src/
├── main.tsx      # Точка входа: QueryClient → BrowserRouter → Routing
├── core/         # Общая инфраструктура (Axios, уведомления, глобальные стили)
├── modules/      # Бизнес-модули (каждый — domain/applications/infrastructure/drivers)
│   ├── ads/        #   Объявления: список, карточка, фильтры, форма редактирования
│   └── ai/         #   AI-помощник: генерация описания и цены
├── routing/      # Маршруты (/, /:id, /:id/edit) и layout
├── shared/       # Общие хуки и утилиты
└── server/       # Fastify-бэкенд для локальной разработки

api/              # Serverless-функции для Vercel (production-аналог src/server)
```
